🛠️ Teil 1: Das Werkzeug

VS Code ist dein Editor, aber GitHub Copilot ist dein Gehirn-Upgrade.

🤖 Copilot Agenten & Modi

  • Cmd/Strg + I Der "Inline Chat": Für kleine Änderungen direkt in der Code-Zeile.
    💡 "Mach das responsiv mit Tailwind"
  • Copilot Edits Der "Architekt": Bearbeitet mehrere Dateien gleichzeitig.
    💡 "Erstelle eine Navbar, verknüpfe index.html und styles.css"
  • @workspace Der Projekt-Kenner: Kennt alle deine Dateien.
    💡 "@workspace Erkläre die Animationen hier."
  • @terminal Der Retter in der Not: Hilft bei roten Fehlermeldungen.
    💡 "@terminal Warum schlägt das fehl?"

🔌 VS Code Geheimwaffen

✨
Prettier Formatiert deinen Code automatisch und macht ihn ordentlich. Nie wieder Chaos!
🌊
Tailwind IntelliSense Schlägt dir Farben, Abstände und Klassen direkt beim Tippen vor.
👁️
Live Preview Zeigt dein fertiges Design direkt in einem Fenster in VS Code an, während du tippst.

🏗️ Teil 2: GitHub für absolute Anfänger

GitHub ist wie "Google Drive für Code", aber mit einer Zeitmaschine (Versionierung).

Repository (Repo)

Dein Projekt-Ordner auf der GitHub-Cloud. Hier lebt dein Code online.

Codespace Geheimtipp

Kein Bock auf lokale Installationen? Klick auf GitHub auf Code > Codespaces. Es öffnet sich ein komplett fertig eingestelltes VS Code direkt in deinem Browser!

Commit

Ein "Speicherpunkt" in deiner Zeitmaschine.

KI-Hack: Copilot kann deine Commit-Nachrichten für dich schreiben! Klick einfach auf das kleine ✨ Funkeln-Icon im Source-Control-Tab.

Push

Deine lokalen Änderungen (Commits) hoch ins Internet schieben, damit sie sicher auf GitHub liegen.
